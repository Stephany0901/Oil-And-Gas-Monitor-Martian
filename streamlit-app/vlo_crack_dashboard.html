Long only, on the doc's own parameters — the short book fails out of sample (2019–2022 max drawdown −56.5% two-sided vs −28.4% long only). Rules are exactly 炼厂利润驱动型股票策略 §3–4 with the final screened parameters from 股票利润模型参数筛选 (gas 0.5 / dist 0.5, z_lb 20, mom_lb 20, z_thresh 1.0, mom_min 0.5, hold_days 3, 5bps commission + 2bps slippage). Inputs: de-RINs US RBOB & HO cracks (months 1–3) and the VLO close, both from the single maintained workbook. Z-score is month-aware: any lookback bar sitting in a different contract month is rebuilt from the second-month cracks — the same contract that is front month today — so the mean/sd window is one consistent contract and the roll gap never enters it. Momentum is unchanged from the source document.

Trend persistence at entry — the forward test

Up-days counts how many of the crack's last 20 sessions the margin actually rose, measured on the entry day from a roll-clean price change with no fitted constants. It does not feed any rule — it is logged so the question can be settled with live evidence rather than more searching.
What the history says. Across 497 signal days the forward 10-day VLO return rises monotonically with up-days (≤10: −0.8% to −2.0% · 11–12: +0.8% to +1.5% · ≥13: +3.6% to +5.0%), and the effect only exists when the z-score has fired (IC +0.26 on signal days, +0.01 otherwise).
What this table says, honestly. Only the ≥13 row reproduces the pattern at trade level. The ≤10 row does not underperform 11–12 here — because the exit rule already closes those positions fast (≈9 bars vs 11+), so the strategy never sits through the bad forward window the raw statistic measures. That is the gap between a +0.28 information coefficient and a +0.08 Sharpe. A conditional exit giving the ≥12 group a longer leash tested at 1.19 Sharpe against 1.09, but only p = 0.070 once the 25-cell search was charged for. Twenty to thirty live trades will settle it.
